# ADR 005 — Effects architecture: registry, dual-kind effects, A/B preview

Status: accepted (M3) · Date: 2026-09-24

## Context

M3 must reproduce every the reference editor effect with preview (Build Plan §10 M3).
the reference editor implements effects two ways (`actions.js` FXBank + `engine.js`):
native WebAudio node graphs rendered offline (EQ biquad chains, Dynamics
compressor, delay network, convolution reverb, WaveShaper distortion) and
sample kernels (hard limiter). Every effect dialog has live A/B preview and
an automation envelope editor.

## Decision

1. **Registry-driven, UI-free definitions.** `src/fx` defines `EffectDef`
   objects (id, label, param specs, kind) registered in `registry.ts`. One
   generic `EffectDialog` renders all parameter UI from specs. Definitions
   are testable without a browser.
2. **Two effect kinds, one apply path.**
   - `kernel` effects are pure functions over `Float32Array[]` (hard limiter,
     noise gate, varispeed rate) — golden-audio unit tested.
   - `graph` effects build native node graphs via `buildGraph(ctx, id,
     params)` — used live for preview and once in an `OfflineAudioContext`
     for apply (faster than realtime, click-free, per the reference editor strategy).
   Apply always replaces the target region through `makeOverwritePaste`,
   so every effect is undoable and stage-then-swap safe (ADR 002).
3. **A/B preview = dual source + crossfade.** Preview starts dry and wet
   paths from the region in parallel (graph effects route through the live
   graph; kernel effects precompute the wet region buffer). Toggling A/B
   ramps dry/wet gains over 30 ms — click-free, no transport restart.
4. **Numeric boundaries are seeded and pure.** Distortion curve and reverb
   impulse response are generated by pure functions with a seeded RNG
   (mulberry32) — deterministic golden tests, no `Math.random` in DSP.
5. **Deliberate deltas from the reference editor (documented, quality-driven):**
   - Distortion curve is scaled ×3 so 0 % = unity gain. the reference editor's curve
     attenuates by 1/3 at zero drive (x/3 — judged a bug); shape unchanged.
   - Hard limiter is a standard feed-forward lookahead limiter (sliding-min
     + release one-pole, linked stereo gain). the reference editor's block-normalize
     version produces block-boundary artifacts; parameters become
     ceiling/lookahead/release instead of max/ratio/lookahead.
   - Delay/reverb mix uses equal-power crossfade (`cos`/`sin`). the reference editor's
     linear mapping sums to +6 dB at center; equal-power keeps loudness
     constant.
   - Delay/reverb apply **keeps the tail** (region grows). the reference editor
     truncates the wet tail to the region length (offline ctx sized to the
     region); truncation loses audible decay.
   - Noise reduction ships as the noise gate (v1 delta per §11); RNNoise
     stays parked. Speed (pitch-preserving stretch) stays parked behind the
     experimental flag; `rate` is varispeed (pitch shifts, per parity list).
     **Status 2026-09-25:** both deltas resolved — RNNoise shipped as E7b
     `fx.rnvoice`; stretch promoted out of the experimental flag (Z1 —
     first-class Effects item; anchors: pitch ±0.5 %, click grid ±2 ms).
   - Graphic EQ 20-band = 20 log-spaced bands 31.25 Hz–16 kHz (the reference editor's
     exact band layout is undocumented; ISO-derived spacing chosen).

## Deviation (logged)

The **automation envelope editor** (draw parameter curves over the
waveform) requires canvas timeline infrastructure that lands with the M5
analysers. It is scheduled with M5; M3 delivers parameter dialogs + A/B
preview + apply. `ParamSpec` reserves `labelKey`/step metadata so envelope
animation can attach per-param later without breaking the registry.

## Consequences

- `src/fx/{curves,limiter,gate,resample,registry,defs,graphs}.ts` are pure
  or ctx-injected → all unit tested (graphs via recording fake context).
- Browser-only glue is thin: `offlineRender.ts` (OfflineAudioContext) and
  `app/preview.ts` (live graph) — excluded from coverage like AudioEngine.
- New effects = one def + one graph builder (+ optional kernel) — no UI code.
