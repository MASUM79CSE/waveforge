# CLEAN_ROOM_LOG — ui-redesign program

Rule (master prompt §3): every pattern adopted from an external product gets one row here,
with the source URL, what was actually observed, and an originality statement. No benchmark
source code, icons, strings, or trademarks are ever copied. Rows written without a real
fetch/observation are not allowed — anything not seen is marked NOT RUN.

Screenshots of live third-party UIs are deliberately kept OUT of the repo (in
`/home/user/wavacity-obs/`, not committed) to avoid shipping third-party visual assets in
the project; observations are recorded as text here.
